# To-Do List App

A simple and minimal to-do list web app using HTML, CSS, and JavaScript.

## Features
- Add, delete, and clear tasks
- Tasks are stored in localStorage for persistence

## Setup Instructions
1. Clone the repository:
   ```sh
   git clone https://github.com/hasini-venisetti/todo-list.git
   ```
2. Navigate into the project folder:
   ```sh
   cd todo-list
   ```
3. Open `index.html` in a browser.

## Technologies Used
- HTML
- CSS
- JavaScript
